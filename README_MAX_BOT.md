# Алерты простоя в MAX (только DM текущей смены)

1. **Только индивидуальные коды (DM)** в **текущей смене**. Нет DM с начала смены → алертов нет (не тянем дату вроде 16.08).
2. **Ralot_L2 / KRO_BOTTLE_L2** — не шлём.
3. Текст: `Задержка на линии {имя как во фронте} N минут.`  
   **N по умолчанию:** **10 → 20 → 50 → 80 → 110 …** (после 20 мин — каждые 30 мин).
4. Возобновление: `Работа на линии {имя} возобновлена, общее время паузы N минут.`
5. Кнопка причины на фронте → **стоп** «Задержка…»; один раз: `{имя} в простое по причине: {причина}`; дальше только возобновление.
6. **08:00 / 20:00** — закрытие открытых простоев + сброс MAX-дедупа по всем линиям.
7. **План линии ≥100%** (факт L1/ТУ ± дезагрегация) — тишина после выпуска **не алерт** и не простой.

## Конфигурация

| Файл | Назначение |
|---|---|
| `max_bot.local.env` | Секреты: `MAX_ENABLED`, токен, chat_id (не коммитить) |
| `max_bot/alert_schedule.env` | Тайминги алертов (опционально, скопировать из example) |
| `max_bot/alert_schedule.example.env` | Шаблон с комментариями |

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MAX_ALERT_FIRST_MIN` | `10` | Первое оповещение (мин тишины DM) |
| `MAX_ALERT_SECOND_MIN` | `20` | Второе оповещение |
| `MAX_ALERT_LATE_EVERY_MIN` | `30` | Шаг после второго: 50, 80, 110… |
| `MAX_REMINDER_POLL_SEC` | `30` | Период опроса сервером (app.py) |
| `MAX_ENABLED` | `0` | Включить бота |
| `MAX_ALERT_EXCLUDE_LINES` | `Ralot_L2,KRO_BOTTLE_L2` | Линии без алертов |

**Не путать:** `DM_SILENCE_BAD_MIN=5` в `app.py` — порог **красной плашки на дашборде**. Бот использует только `MAX_ALERT_*`.

`max_bot.local.env` и `max_bot/alert_schedule.env` подхватываются автоматически (`max_bot/config.py`).
